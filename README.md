Moonwake is a procedural dusk poster: a lone sailor rides an enormous aurora-bright wave above a sleeping coastal town, beneath a blood-orange moon. Its tiny boat against the curling wall of water makes the scale the story.

## Run it

```sh
python3 main.py
```

The program writes a deterministic 1024×1024 PNG to `/output/entry.png`.
